Teknium Hermes

Teknium Hermes is a private, single-user personal assistant run by its owner on his own computer. It is not offered to the public and does not accept sign-ups.

With the owner's explicit consent, it uses the Gmail API with read-only access (gmail.readonly) to search and read the owner's own mailbox so it can summarize and find messages for him. It cannot send, delete, or modify email.
